# Hi 👋

Welcome to Laravel Presentations, a webapp build with Laravel and Vue to create and present your talk via the web.

Status: in development

## Setup

```bash
npm install
npm run build
php artisan migrate:fresh --seed
```

or using `pnpm`:


```bash
pnpm install
pnpm build
php artisan migrate:fresh --seed
```

## Running the app:

```bash
composer run dev:ssr
```
